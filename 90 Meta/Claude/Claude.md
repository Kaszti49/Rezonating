# Claude

Claude is the third team member: research, datasheet checks, code review, documentation, and keeping this vault tidy.

## How Claude works here
1. **Start of a session:** reads `CLAUDE.md` → [[Handoff]] → [[Home]] → its queue (work with `owner: claude`, inbox notes tagged `#ask-claude`).
2. **During:** writes notes using the exact templates and allowed values in [[Vault rules]]. Adds one line under `## Claude` in today's daily note.
3. **End of a session:** appends to [[Session log]] and rewrites [[Handoff]] so the next session (which remembers nothing) can continue.

## What Claude can do
- Read and edit every note and file in this folder (while the computer is linked)
- Research on the web, check datasheets, compare suppliers
- Review code and schemas, write docs, draft the OTIO text when asked
- Keep properties consistent, fix broken links, update the dashboard and Bases

## What Claude can't do
- Remember anything that isn't written in the vault
- Push to GitHub (the GitHub account isn't linked to Claude), solder, or run tests on the real hardware
- Make decisions: it proposes, you two decide

## Asking Claude
- Quick: tag an inbox note `#ask-claude`.
- Real work: a work note with `owner: claude`, a goal, and "Done when" boxes.
