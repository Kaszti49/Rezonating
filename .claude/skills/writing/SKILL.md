# Playbook: writing

- Lead with the point. Short sentences, plain words, active voice. No filler, no hype, no claim
  the project hasn't measured.
- Every technical claim matches the repo or the vault: open the source and keep numbers identical.
  Not decided yet → say so.
- English unless asked otherwise. Hungarian (OTIO, study lessons) is natural Hungarian, not a
  translation of English sentence structure; flag it for a native speaker's skim.
- Docs that ship with the code (`docs/`, READMEs) never mention vault-only things: the vault is
  removed before the repo goes open source (D-012).
- Finish with a short list of claims or numbers a person should confirm before it goes out.
